# /attribution

`index.html` here is the Crump Group Amazon Attribution dashboard, served verbatim at
`/attribution/index.html` and framed by the app's `/#/attribution` page (`src/pages/Attribution.jsx`).

It is REWRITTEN EVERY WEEKDAY by the Cowork scheduled task `refresh-amazon-attribution-dashboard`
(git push from the sandbox with a repo-scoped token). Do not hand-edit it; edits are overwritten
the next morning. The app bundle is never rebuilt for a data refresh.
